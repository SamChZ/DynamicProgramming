# Dynamic Programming – Symbolic AI Practicum

Gemaakt voor het Dynamic Programming practicum van het vak Symbolic AI aan de Universiteit Leiden (2020).

Implementeert Value Iteration en Q-Value Iteration op een grid world die wordt ingeladen vanuit `prison.txt`. Na het uitvoeren kun je stap voor stap door het optimale beleid lopen of de greedy actie automatisch laten uitvoeren.

## Uitvoeren

```bash
python dynamic_programming.py
```

Volg de instructies in de terminal — het vraagt je om enter te drukken om value iteration te starten, daarna Q-value iteration, en laat je daarna de resultaten doorlopen.

## Vereisten

- Python 3
- NumPy
- `world.py` (zit bij de projectbestanden)
